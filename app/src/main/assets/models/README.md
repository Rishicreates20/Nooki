# 3D pet models

`nooki.glb` is Nooki's original model, generated by `tools/pet-model/generate_nooki_glb.py`
(re-run it after tweaking colors or poses). It ships 4 looping clips:
`Sleeping`, `Happy`, `Alert`, `Overwhelmed`.

## Using your own model

1. Drop `your_pet.glb` here (binary glTF keeps textures inside one file; a `.gltf` works too if its
   `.bin`/textures sit next to it).
2. Name your clips `Sleeping` / `Happy` / `Alert` / `Overwhelmed`, or use one of the aliases in
   `MoodClipAliases` (`NookiPet3D.kt`), e.g. `Idle`, `Jump`, `LookAround`, `Shake`.
3. Pass `modelAssetPath = "models/your_pet.glb"` to `NookiPet3D` (or replace `nooki.glb`).

Tips: keep it under ~20k triangles and 1024px textures for smooth 60fps on mid-range phones; the
model is auto-scaled to a 1-unit cube and centered, so export scale doesn't matter. Animate child
nodes/bones, not the root node: the app drives the root for tap and tilt reactions.
